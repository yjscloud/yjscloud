# 章北海 / yjscloud

自托管工具与运维自动化，主要在 Proxmox / Linux 这一侧。

## 最近在做的

- **[ProxCenter](https://github.com/yjscloud/ProxCenter)** — Proxmox VE 8.x / 9.x 管理面板：
  虚拟机与 LXC 容器的全生命周期、cloud-init 模板流水线、监控大盘、浏览器内 VNC/串口控制台、
  多用户权限与操作审计，另含 SSH 防暴力破解、端口异常检测与安全基线加固。Apache-2.0。
